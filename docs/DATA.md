# 数据接口契约

第一版输入是本地 CSV 数据集。没有内置真实行情下载器，也不会从演示股票生成可用于交易的信号。你选定数据服务后，由适配器把数据转成此契约；数据许可和账户密钥由服务器环境管理。

目录包含四个文件（10:00研究及回测必须提供 intraday.csv）：

- `calendar.csv`：单列 `date`，YYYY-MM-DD，唯一、升序，真实模式须为交易所交易日历，覆盖下一交易日。演示仅用工作日，不代表实际交易日。
- `bars.csv`：下表字段，每个交易日、每个证券一行。
- `metadata.json`：`kind` 为 `real` 或 `demo`，`source` 描述来源，`expected_symbols` 为日期到完整证券代码列表的映射。清单应独立来自数据供应方证券目录，不能简单用已下载行生成，否则无法检测漏行。

|字段|类型及含义|
|---|---|
|date|交易日期|
|symbol|带交易所后缀的字符串，保留前导零，例如 600000.SH|
|name|当时证券名称|
|board|SSE_MAIN / SZSE_MAIN；其他板块可导入但不会入选|
|listed_date|上市日期|
|open, close|未复权开盘与收盘价格，正数|
|volume|成交股数，不是手数|
|amount|成交金额，人民币元|
|adj_factor|正数、历史连续的复权因子，close × factor 用于历史收益计算|
|suspended, risk_warning, delisting|当日真实状态，严格为 0 或 1|
|limit_up, limit_down|当日适用涨跌停价格，0 表示无该限制；由供应方按历史规则提供|
|buy_lot|当日适用最小整手数量，正整数；此实现仅用于沪深主板普通整手交易|

停牌日仍需有记录，使用供应商上一有效价格、零成交量和 suspended=1；不得省略该证券。持仓缺行会停止运行。应保留退市股票的历史行情、历史证券状态，不能用今日上市名单回填历史。

导入前独立校验上市/退市区间、交易日覆盖、量纲和复权因子。程序检查格式、重复行、数值、当日清单完整性，因子要求连续历史窗口。缺少历史行的证券不会参与评分。

当前仅有量价因子；没有财务或公告因子。未来接入财务时必须保存公告发布时间、供应方可用时间和修订版本，报告期不能作为数据可用时间。

公司行动：当前持仓涉及复权因子变化时，回测与信号流程停止。真实现金股息可记录 DIVIDEND，但送转、配股、退市结算及公司行动核销流程尚未实现；不能绕过检查用于含这些事件的策略评估。

配置中的费用是单一版本；跨费率调整日期的真实历史回测需分段或增加费率时间表，不应把演示费率解释为历史真实费率。


## 10:00执行观测（新增必需数据）

`intraday.csv` 字段为 `date,symbol,timestamp,price,volume,tradable`。

- timestamp 严格为 `YYYY-MM-DDT10:00:00+08:00`，北京时间交易日10:00。
- price 为截至10:00的最后成交价，来自结束时间为10:00的分钟线收盘价或等价时点快照，不能使用开始时间为10:00、实际含10:01信息的分钟线收盘价。
- volume 为结束于10:00的前一分钟成交股数，不是全天成交量、不是手数。
- tradable 为该分钟存在有效交易且观测新鲜时的0/1标记。停牌或无有效成交不得用旧价冒充可成交报价。
- 数据商时间戳若表示分钟起点，应由适配器明确转换；必须记录其定义。
- 未提供时，日频特征仍可计算，但研究标签标记 missing_execution_quote，10:00回测拒绝回退到开盘价。

合成数据生成器会独立生成明确标记为 DEMO 的10:00价格，不是从真实日线推导真实分钟行情。人工操作在10:00附近的偏差目前以滑点近似，后续需要真实分钟路径做执行延迟压力测试。
