# 数据准入与存储

只采集研究任务需要的数据，不因时间近就自动全量采集。当前实现没有全量分钟线长期归档。

## 当前已实现

长期保留日线、每个交易日10:00观测、复权因子、证券状态、历史数据修订、因子公式和冻结预测。10:00数据是训练标签的基础，无论多旧均不能降为日线；相同标签定义在所有历史日期保持一致。

BaoStock回填使用结束于10:00的30分钟线收盘价，提取后其他分钟记录只在内存中短暂存在。一个正常交易日收到8根30分钟线，只留下1个10:00观测。保留源请求范围、收到行数、内容哈希、实际保留行数和更新时间；成交量明确标记为30分钟窗口，不冒充一分钟成交量。

`core/` 保存逐证券核心数据，数据商修订保留在 revisions.jsonl。`dataset/` 是可重建的标准CSV视图。按唯一日期/证券键合并，不重复追加整段历史；每次增量重拉最近7个自然日以检测修订，已到最新交易日则跳过重复拉取。

`configs/storage.json` 设置2 GiB数据目录预算、512 MiB最低磁盘余量。超限会停止抓取并保留核心数据，不自动删除训练标签。该配置控制行情数据目录，实验与预测结果位于独立目录，后续扩大样本时需单独监控与归档。

## 后续确有需求时的分层方案（尚未开启）

- 最近20个交易日：按需缓存完整1分钟线，用于检查10:00附近的人工成交偏差。
- 较老分钟数据：仅在研究已需要相应盘中特征时保留5/15分钟汇总。
- 更老数据：保留日线、10:00观测及已定义的稳定盘中特征。

不能用1分钟特征训练近期样本、用不等价的15分钟特征训练早期样本却当作同一个因子。若某个因子需要完整分钟路径，要为它单独建立有来源与保留期的数据产品，或限制该因子的可用训练区间。

当前只实现提取式存储和容量准入，没有假装实现尚未需要的多层自动降采样。没有执行历史数据删除。
