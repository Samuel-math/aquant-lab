# 188只主板研究底池的筛选口径

此筛选与已冻结的24只模拟试验分离，不修改任何历史预测、计划或账户。当前版本的数据日为2026-09-28，适用于未来研究；不能将今天筛出的名单回填到过去并声称没有幸存者偏差。

## 范围及数据

起点为BaoStock当日沪深主板A股名单。剔除非正常上市、上市未满两年、行业未知、ST、最新交易日停牌、近60个交易日交易不足57天、价格低于3元、近20日平均成交额不足5000万元、TTM盈利或净资产非正/估值缺失者。

板块采用证监会行业分类，不是所有主题概念板块。活跃度衡量的是通过上述基本筛选的行业子样本；不足以判断行业长期经济前景。

## 板块初筛

计算近60日收益相对合格主板股票中位数、近20日/60日日均成交额比值、近20日上涨股票占比。三者横截面百分位权重分别为40%、35%、25%。只有活跃度处于行业后25%，且以下三条至少满足两条，才排除：

- 60日相对收益为负；
- 20日/60日日均成交额比低于0.8；
- 20日上涨股票占比低于40%。

不把短期表现弱等同于永久无投资价值，不因行业名称主观封杀。

## 财务深查

为限制公开数据接口的负荷，每行业先取流动性60%与低波动40%综合排序前35只，最多深查1000只。未进入深查范围者是预算/预筛限制，不代表财务质量不合格。

检查2024、2025年报及2025、2026年中报，披露日晚于数据日的记录不可进入筛选。两年年度净利润及两期中期净利润均为正，两年年度ROE各不低于6%，2026中期ROE不低于2.5%，中期净利润同比下降不超过30%。

非金融股：资产负债率不超过80%；两年经营现金流/净利润均为正且均值不低于0.6。金融股：负债率不超过96%，不套用非金融现金流规则；此版本没有不良贷款率、资本充足率或保险偿付能力等专门审计，不能把其评分解释成完整金融机构风控结论。

供应方财报可能存在事后修订，披露日过滤不等于完整历史版本数据库；保存原始响应供审计。

## 最终排序

60%财务质量、15%行业活跃度、15%流动性、10%低波动。非金融质量包含两年ROE、较弱年度ROE、现金流质量、中期利润增长、负债；金融质量不使用经营现金流，改用盈利稳定性。各指标作百分位，金融和非金融分组。

每个行业最多24只，金融合计最多38只，依次选取188只。合格数不足188时明确失败，不降低标准凑数。研究底池不按账户金额删除高价股，输出“100股是否适合当前单股预算”供组合层另行约束。
