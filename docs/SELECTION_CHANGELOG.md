## 1. 范围与版本口径

- 股票范围：沪深主板，不含创业板、科创板、北交所。
- 底池负责确定可以研究的股票；每日因子模型负责产生信号；组合与执行规则负责资金、费用和成交核算。这三类规则分别记录，不能把底池排名直接当作买入顺序。
- 已约定的收益标签为下一交易日10:00买入至再下一交易日10:00的价格收益，即 `P(T+2,10:00) / P(T+1,10:00) - 1`，交易日而非自然日。组合收益还须扣除可配置费用和滑点。
- 本月观测为1万元、空仓起步的模拟组合；真实交易由用户手动操作。日频更新数据和训练，不等于每天改变底池规则。
- 版本号用于追踪方法，不表示收益优劣。当前尚无证据证明V2.1的扣费样本外收益优于V1。

## 4. V1：盈利质量底池

### 条件与评分

1. 正常上市、上市至少730个自然日、行业已知。60个日线样本齐备，其中至少57日交易；最新日可交易且非ST。收盘价至少3元，20日平均成交额至少5000万元，PE(TTM)与PB均为正。
2. 对行情合格样本按行业计算活跃度：60日相对收益40%、成交额比35%、20日上涨家数占比25%，各项按百分位合成。行业分数处于末25%，且“相对60日收益为负、20/60日成交额比低于0.8、上涨占比低于0.4”至少满足两项时，剔除该行业。
3. 行业内以60%流动性、40%低波动预选最多35只，全局深查预算最多1000只。本轮实际深查842只；未进入深查不等于财务不合格。
4. 2024、2025年度及2025、2026中期净利润均为正；年度ROE至少6%，2026中期ROE至少2.5%；中期利润同比不低于-30%。非金融负债率不超过80%，金融不超过96%。非金融两年经营现金流/净利润均为正且均值至少0.6。
5. 财务评分只区分金融与非金融，尚未逐行业比较。非金融质量权重：平均年度ROE35%、较弱年度ROE20%、现金流质量20%、中期利润增长15%、低负债10%；金融分别为45%、25%、20%、10%，不使用工业企业现金流门槛。
6. 最终分数：质量60%、行业活跃度15%、流动性15%、低波动10%。按总榜选188只，每行业最多24只，金融合计最多38只。

### 结果、问题与验证

3196只主板样本 → 1781只行情合格 → 842只财务深查 → 333只财务合格 → 188只入选，覆盖45个行业。行业初筛剔除了19个行业。

主要问题是盈利和ROE硬门槛、低波动预选偏向成熟企业；金融/非金融两组仍不足以解决跨行业可比性。金融入选30只，其中银行24只；科技行业代理只有7只。投入期科技企业可能在进入评分前就被排除。

本轮完成缓存数据复跑及门槛、报告期间、披露日期、数量和集中度核验。此验证说明规则执行一致，不是盈利能力验证。完整参数以V1配置及[筛选脚本](../scripts/select_quality_pool.py)为准。

## 6. V2.1：当前研究条件

### 基础准入与比较方式

- 保留上市两年、正常交易、非ST、至少3元、20日均成交额至少5000万元、正PB等基础条件；取消正PE要求。
- 不再按活跃度整行业剔除；行业活跃度只占总分5%。每行业取成交额前25与60日强度前20的并集深查，不再用低波动预选或全市场预算截断。
- 所有个股评分在同一证监会细分行业、同一评价路径内计算百分位。样本数不足8时按`n/8`向0.5收缩，单样本为0.5，不回退到跨行业比较。
- 非金融先判断成长条件，不满足再判断成熟条件，不能事后挑选得分更高的路径。路径只是筛选分类，不是对公司真实生命周期的认定。

### 财务准入

| 路径 | 条件 |
| --- | --- |
| 成长盈利 | 2025收入同比≥10%，2026中期收入同比≥20%；相关收入为正且可得；中期毛利率≥10%，同比下降≤2个百分点；负债率≤65%，流动比率≥1.2，现金比率≥0.5；最新中期盈利 |
| 成长亏损观察 | 满足成长条件，最新中期亏损时另要求现金比率≥1.5、流动比率≥2、负债率≤50%，且净利润/收入比率同比改善；不用负利润基数的增长百分比衡量改善 |

### 已知缺口

研发投入和产出、现金消耗周期、融资依赖等专项数据未齐备，不能把现金比率视作现金可支撑月数，也不能断言亏损由研发造成。金融企业的不良贷款、资本充足率及保险偿付能力尚未补齐。本版仍是有缺口的研究筛选，不是完整尽调或收益保证。

当前脚本财务期间对应本次2026年筛选，尚未实现自动滚动所有财务期间。未来刷新须先核验期间逻辑。不要把“每日更新行情”误认为“自动更新全部财务规则”。

## 7. 后续按实际经验更新

### 更新触发与节奏

- 每日记录信号、实际可成交性、费用、滑点、漏单和数据缺失；这些观测不自动触发改规则。
- 建议每月复查底池结构，每个财报披露周期复查财务条件；每周检查行业覆盖及数据异常。此处是维护建议，**不是已经新增的定时任务**。
- 数据错误、停牌/ST等影响准入的问题及时处理并记录；新增假设、门槛或权重作为新研究版本评估，不在冻结试验中悄悄更换。
- 比较新旧版本时保持数据截止日、成本和评价口径一致；关注扣费样本外收益、回撤、换手、行业集中和成交可行性。记录失败实验，不能只保留成功版本，也不据短期胜负宣布方法有效。
- 新池若有足够历史时点数据，应做滚动样本外检验；否则用独立前向观察，明确样本不足。当前名单回填历史不构成无偏证据。

### 每次变更必须记录

1. 版本号、日期、数据截止日、状态（提案/研究完成/已启用/已停用）。
2. 观察到的问题、实际样本区间及证据；区分工程错误与投资假设。
3. 旧条件→新条件、修改理由、阈值与权重；涉及底池、模型还是执行层。
4. 对应代码提交、配置、名单、数据/规则摘要及可复现命令或文档。
5. 新旧入选数量、行业分布、名单增删、验证结果与尚未验证事项。
6. 若实际启用，记录生效时间、适用试验和回退版本；若未启用，明确标注。

配置和名单使用新版本文件或目录保存；历史记录只作明确标注的勘误，不倒改当时结论。涉及筛选逻辑的代码提交须同步更新本文件，具体约定见[仓库维护指引](../AGENTS.md)。
